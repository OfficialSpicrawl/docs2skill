# docs2skill film: prompt and beat sheet

<context>
docs2skill (CLI file `llms-txt.mjs`, built on the Spicrawl API) turns any docs site into an agent skill: a `SKILL.md` folder with one reference file per page, plus `llms.txt`, `llms-full.txt` and an `AGENTS.md` index. Nothing is written by a model; every line comes from the scraped pages.
This film plays on the GitHub README (as a silent GIF) and on X/LinkedIn (as the MP4 with narration). It must read with the sound off: the captions carry the story.
Read `videos/BRAND.md` first. It holds the brief, the look, the brand element, the components and what we may claim. This prompt only adds the story.
</context>

<inputs>
Decided: 1920x1080, 30 fps, dark, 19.10 s (573 frames). Music: none. Narration: Kokoro `af_heart`, one clip per caption (`public/audio/docs2skill/c1..c4.wav`, measured 2.925 / 4.75 / 2.675 / 3.2 s), mixed by `scripts/mix.ts` to about -16 LUFS. Cues in `src/docs2skill/cues.ts`.
Real data: the log, the tree and `SKILL.md` in `src/docs2skill/real.ts` are from a live run on 2026-10-23: `node llms-txt.mjs https://docs.spicrawl.com --max 8 --skill spicrawl-docs` (8 pages, about 8 credits).
</inputs>

<direction>
Calm and exact. A terminal doing one real job, then the file it made, then the one command that installs it.
Ingredients (from the interview): UI only (a terminal) · one short caption per beat, shown exactly while its narration clip plays · clean cuts · frame-driven typing and a block cursor.
Only the product's own surfaces, colors, borders and effects. White is the only accent.
Banned: music, hue, glow, gradients, particles, bouncy easing, a fake agent UI, any claim of search, crawling or AI extraction, any line of terminal text that the tool does not print.
</direction>

<cast>
- Brand element: the Spicrawl mark on the end card only.
- Cursors: none (the terminal types by itself; the block text cursor blinks at rest).
- Demo world: docs.spicrawl.com, skill name `spicrawl-docs`, output directory `out/`.
</cast>

<structure>
Four scenes, clean cuts, back to back (no music grid; beats sit on the narration clips).

1. Run (0.00 to 5.30 s). "Turn any docs site into an agent skill." The command is typed, then the tool's real log: discovery, "Fetching 8 pages, about 8 credits (1 per page).", progress 0/8 then 8/8, the files written, the install hint, the prompt back.
2. Files (5.30 to 11.30 s). "SKILL.md, llms.txt and AGENTS.md, in seconds." `tree --noreport out` streams in (the three named files in full white, the rest dimmer), a cut to `SKILL.md` with its `name:` and `description:` lit, then a 0.7 s scroll to the Reference list (all seven page entries).
3. Install (11.30 to 14.90 s). "Drop it into Claude Code or Codex." The two README copy commands are typed: `cp -r out/spicrawl-docs ~/.claude/skills/` and `cp -r out/spicrawl-docs .agents/skills/`. No agent UI.
4. End card (14.90 to 19.10 s). "Free and open source. Built on Spicrawl." Mark, `docs2skill`, `github.com/OfficialSpicrawl/docs2skill`, `docs2skill.spicrawl.com`, each rising in 0.15 to 0.2 s steps.

<build>
1. Remotion in `videos/`, versions pinned (BRAND.md "Workspace"). Kit in `src/kit/`, this film in `src/docs2skill/`.
2. Every style is a pure function of the frame (`useTime()`); the cursor blink, typing and scroll are closed-form in t.
3. `cues.ts` is the beat sheet as data; scene code never holds a literal frame number.
4. Narration: `scripts/narrate.sh` then `bun scripts/mix.ts`. Review: `bun scripts/stills.ts out/review/rN <frames> --composition Docs2Skill [--debug]`.
5. Final: `bun scripts/render.ts v1` (PNG frames, one BT.709 conversion, H.264 + AAC, GIF, poster, stills), then `uv run --with numpy --with imageio-ffmpeg python3 scripts/verify.py out/docs2skill/v1 --duration 19.1 --fps 30 --bg 22,24,27 --bg-at 40,40 --no-seam --audio`.
</build>

<gotchas>
Frame 0 has a terminal in the middle, so the ground is read at (40, 40), not at the center. The master must never be read as full range (it lifts #16181B). JetBrains Mono's latin subset has no box-drawing glyphs: draw tree guides. Terminal text never wraps: the longest real line is 107 columns. Keep the install line and the "Codex-style repos" line exactly as the tool prints them.
Claims: only what the tool prints and the README says. "In seconds" is the brief's wording for one 8-page batch job.
</gotchas>
