Pasting a docs site into a prompt does not scale.

I built docs2skill, a small open-source CLI. Give it a docs URL and it writes an agent skill folder (SKILL.md plus one reference file per page), llms.txt, llms-full.txt and an AGENTS.md. Claude Code and Codex can load it and open only the pages a task needs.

It reads the sitemap and fetches pages as markdown through the Spicrawl API. No model generates anything, so the same site gives the same files.

It is not a crawler: pages come in sitemap order. The free plan covers about 1,000 pages a month.

Repo, a 5-page browser demo and the demo video are in the first comment.
